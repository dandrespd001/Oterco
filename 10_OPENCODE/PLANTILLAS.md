# Plantillas de intervención

Comandos, exit codes y resultados:

## Retorno de revisión

```text
ID, commit/diff y contratos revisados:
Veredicto acotado:
Hallazgo / gravedad / archivo / reproducción / impacto / cambio mínimo:
Pruebas comprobadas y no ejecutadas:
Revisión visual: sí con capacidad real | pendiente:
Límites y próxima acción:
```

## Acta de sesión

```text
Fecha / sitio / rama / commit si existe:
Unidades completadas y evidencia:
Unidades parciales y archivos tocados:
Decisiones autorizadas y origen:
Pendientes técnicos/comerciales/remotos:
Modelos utilizados y bloqueo de cuota si existe:
Próxima tarea/unidad y contexto mínimo:
```

No copiar claves, cuerpos de mensajes personales o documentación privada. No solicitar cadenas internas de pensamiento; decisiones y evidencia bastan para continuar.
