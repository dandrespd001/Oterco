# Checklist de identidad, apariencia y revisión visual

Estado inicial de todas las comprobaciones: **pendiente**. Registrar viewport, commit, navegador, fuentes efectivamente cargadas, ruta y quién revisó. Marcar cada ítem con evidencia; no cambiar casillas para aparentar avance.

- [ ] V-01. Se ha leído la ficha visual local y la matriz de independencia, no la plantilla de la otra web.
- [ ] V-02. Wireframes completos de escritorio y móvil muestran navegación, hero, interior, acción y pie.
- [ ] V-03. Fuentes locales autorizadas y sin errores de carga; la captura no usa un fallback accidental.
- [ ] V-04. Paleta, jerarquía y distribución de superficies corresponden al sitio; controles cumplen contraste.
- [ ] V-05. H1, H2, cuerpos, labels y ayudas tienen tamaños/ritmo locales; no hay estilos cruzados.
- [ ] V-06. La composición se sostiene sin sustituir solamente fotos, logo o color.
- [ ] V-07. Móvil no reproduce la misma pila de tarjetas de la otra marca.
- [ ] V-08. Fotos pertinentes, procedencia registrada, recortes razonables y sin atribuciones falsas.
- [ ] V-09. Estados de hover, foco, activo, error y deshabilitado legibles; ningún dato depende solo del color.
- [ ] V-10. A 320/390/768/1440 CSS px no hay solapamiento ni scroll horizontal de página no justificado.
- [ ] V-11. Zoom 200 %, prueba de reflow 400 % y cadenas largas conservan lectura y controles.
- [ ] V-12. Menú/anclas usables con teclado y sin JS; cabecera no oculta destino/foco.
- [ ] V-13. Movimiento local y reduced-motion correctos; el contenido no depende de una animación para aparecer.
- [ ] V-14. El primer CTA y el contacto se encuentran sin atravesar toda la página.
- [ ] V-15. Capturas completas y detalles examinados realmente, no solo HTML/DOM o puntuación de Lighthouse.
- [ ] V-16. No aparecen placeholders, textos de desarrollador, créditos ficticios o recursos rotos en producción.
- [ ] V-17. Comparación conjunta en color y copia de revisión en gris/sin logos. Solo aplicable cuando existan ambos prototipos.
- [ ] V-18. Se documenta aprobación o cambios pendientes. Sin porcentaje de originalidad ni promesa de anonimato del autor.

En Puerta Abierta el primer cierre comprueba su identidad contra la matriz y la referencia ganadera, no contra una segunda web inexistente. En OTERCO se revisan las dos capturas ya disponibles. Una captura automática no demuestra que el modelo tenga visión; probar la capacidad o solicitar revisión humana. Nunca actualizar todos los snapshots para ocultar cambios no revisados.
