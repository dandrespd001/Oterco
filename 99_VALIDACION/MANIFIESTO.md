## Repetir la comprobación (opcional)

Guarda este bloque en `verificar-manifiesto.mjs` y ejecuta desde la raíz del flujo `node verificar-manifiesto.mjs 99_VALIDACION/MANIFIESTO.md`, o desde la raíz general `node verificar-manifiesto.mjs MANIFIESTO.md`. Solo usa Node estándar. Un archivo añadido después de esta entrega no figura automáticamente en el manifiesto; los cambios legítimos de implementación producirán diferencias esperadas. No mezclar esa comparación con las pruebas de la web.

```javascript
import { readFile, realpath } from "node:fs/promises";
import path from "node:path";
import { createHash } from "node:crypto";
const root = await realpath(process.cwd());
const arg = process.argv[2] ?? "MANIFIESTO.md";
const text = await readFile(path.resolve(root, arg), "utf8");
const rows = [...text.matchAll(/^\| `([^`]+)` \| `(\w{64})` \|$/gm)];
if (!rows.length) throw new Error("Manifiesto sin entradas");
let bad = 0;
for (const [, rel, expected] of rows) {
  const full = path.resolve(root, rel);
  if (path.isAbsolute(rel) || !full.startsWith(root + path.sep)) throw new Error("Ruta fuera de la raíz");
  try {
    const actual = createHash("sha256").update(await readFile(full)).digest("hex");
    if (actual !== expected) { console.error("CAMBIADO:", rel); bad++; }
  } catch { console.error("AUSENTE:", rel); bad++; }
}
console.log(`${rows.length} archivos comprobados; ${bad} diferencias`);
process.exitCode = bad ? 1 : 0;
```
