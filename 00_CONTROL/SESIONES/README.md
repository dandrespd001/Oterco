# Actas de OTERCO

Un archivo por sesión o hito, nombre fecha-ID-unidad.md. Lo escribe el coordinador con decisiones, cambios, comandos, resultados reales, pendientes y siguiente paso. No mezclar credenciales, datos reales, aprobaciones inventadas o el historial del otro sitio. Tras cada unidad actualizar también ESTADO y ESTADO_TAREAS.

Las pruebas y capturas de implementación pertenecen a docs/implementacion; enlazar solo dentro del repo y no publicar estos directorios. Las fichas normativas no se reescriben para simular progreso.
